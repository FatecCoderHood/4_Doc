# 👤 Manual do Administrador

> **Público-alvo:** usuários com perfil `Administrador`

---

## 👥 Gerenciamento de Usuários

### Criar novo usuário
1. Acesse **Usuários**
2. Clique em **"Novo Usuário"**
3. Preencha os dados e selecione o perfil
4. Clique em **Salvar**

### Editar usuário
- Clique no botão **"Editar"** ao lado do usuário desejado

### Excluir usuário
- Clique no botão **"Excluir"**

---

## ⚙️ Permissões de Acesso

- **Administrador**: acesso total
- **Consultor**: cadastro e envio de áreas
- **Analista**: edição e validação
